## 1. 分析基礎與假設

| 項目 | 內容 |
|---|---|
| 負載基礎 | 2018年5月 週六半尖峰 實測系統同時負載 2432 kW |
| 分散係數 | 0.503(各台實載加總 4,834 kW → 2432 kW) |
| 功率因數 | 採變壓器細部資料之運轉功因;已對應變壓器之並聯電容已折入功因,不另重複計入 |
| 負載分布來源 | 校園變壓器細部資料 TR-1~TR-52「平均負載」比例 |
| 資料來源 | 校園變壓器細部資料 (廠牌/容量/運轉值/電容) |
| 模型範圍 | 37 台變壓器、64 母線 (HV 27 / LV 37)、40 負載點 |
| 演算法 | Newton-Raphson (pandapower 3.4.0) |
| 系統頻率 / 主電壓 | 60 Hz / 11.4 kV |

```
負載分配方法 (Load Allocation Method)

  Step 1  原始有功 (相對權重)
          P_raw,i = 各變壓器實測平均負載 (變壓器細部資料)
          ΣP_raw = 4,833.5 kW

  Step 2  分散係數縮放 (守住系統同時負載)
          k = 系統同時負載 / ΣP_raw = 2432 / 4,833.5 = 0.5032
          P_i = P_raw,i × k        (各棟同比例縮放,總和 = 系統同時負載)

  Step 3  無功 (由各台運轉功因)
          Q_i = P_i × tan(arccos(pf_i))

  說明: k 即需量參差/分散係數,反映各棟不同時達峰;
        各台平均負載直接加總會高於系統同時負載,故須以 k 縮放。
```

> ⚠ 模型未含(真實有)建物:E圖書資訊館(TR-4~8)、H1第一宿舍、H6第六宿舍(TR-31~34)、U棟優活館、污水處理廠、O高齡福祉館。故模型總負載代表上述同時尖峰下「已建模部分」的分攤。
