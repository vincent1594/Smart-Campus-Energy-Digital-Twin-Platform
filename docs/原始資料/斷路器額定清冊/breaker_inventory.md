# 斷路器 / 高壓開關額定清冊

> 來源:`研究資料/1.高壓單線圖/` 共 30 張竣工單線圖(2009–2024)。
> 用途:作為 pandapower 模型 **斷路器遮斷容量(kA)校核** 與 **連續電流(AT)餘裕校核** 的額定基準資料。
> 數字一律照圖照抄;模糊或疑義處標「?」並於備註說明。型式/油乾多數圖未標。

---

## 一、重點發現

1. **校園分兩層配電,開關等級完全不同:**
   - **總/受電站(有 VCB/GCB,可遮斷故障)** — 才是 kA 校核的對象。
   - **末端建築站(只有 LBS 負載開關,不遮斷故障)** — 沒有 kA 可校核,故障保護靠上游總站。

2. **模型的台電受電點 = `X棟新設總變電站`**(本次清冊最大發現)。
   它「FROM TPC 台電配電場 3φ3W 11.4–22.8kV」經 MOF 受電,內含 **MVCB + VCB1~VCB14**,
   出線去向與本 repo `FEEDERS`(VCB1–12)幾乎一一對應(見第四節)。
   → kA 校核應以此站為錨點。

3. **遮斷 kA 並非全校統一**,需逐站採用:
   - **16 kA**:X棟總站、W、I、U、O、V、六舍、J(GCB)— 多數新站。
   - **25 kA**:E棟、T棟甲配/乙配。
   - **12.5 kA**:N棟(GCB)。
   - 連續電流:VCB 多為 **630A**;主 MVCB 視站別 **600 / 800 / 1250A**;DS 600~1250A。

4. **南/宿舍區另有獨立總站**(`一舍總變電站` / `U棟主變電站` / `O棟高壓總配電站`),
   送 第一/第六學生宿舍、資訊大樓SP、運動館、高齡大樓 — 屬目前模型(北電錶)範圍外。

5. **油/乾式**:多數圖未標。明確標「乾式 MOLD TYPE」者:I 棟 TRS1–4、V 棟 TR1/TR2。
   (與模型現有 `type:乾` 設定可交叉核對。)

## 五、待補資料(校核 B 還缺的)

1. **台電分界點短路容量 MVA**(`ext_grid` 的 `s_sc_max_mva`)— 在台電受電/併聯審查文件,圖上無。
   暫可用開關設計值反推上限:11.4kV × 16kA × √3 ≈ **316 MVA**。
2. 一舍總站 / K 棟 / L 棟 VCB 的 kA 需現場銘牌複核(圖面未逐櫃印或疑誤標)。
3. 變壓器油/乾式多數未標,以現有模型 `type` 欄與現場銘牌為準。
