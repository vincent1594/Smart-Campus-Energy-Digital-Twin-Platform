# V1 驗收 / 校正清單

> 目的:把平台目前用的**假設值**逐一升級為**實測/官方值**,並釐清**模型涵蓋範圍**。
> 每列說明:現用假設 → 需要的真實資料 → 由誰提供 → 影響哪些功能。
> 標 🟡=待校正假設、🔴=範圍/資料缺口、✅=已確認。
> 對應平台「驗證中心」分頁;校正完成即可把該分頁的數字從「規劃估算」升級為「可稽核」。

---

## 如果只能先要三樣(投報率最高)

1. **近 12 個月台電電費帳單**（含需量、功因、罰款明細）——一次校正電費、超約、功因三條主線,並驗證我們估的超約罰款 ~NT$ 231 萬 準不準。
2. **台電合約**（契約容量、適用費率方案）——所有電費/罰款計算的基準。
3. **南電錶 / 未建模 15 台變壓器的歸屬與資料**——釐清模型只代表北電錶區,或補上全校。

## 校正後可宣稱的升級

- A1–A5 校正 → 電費/超約/契約最佳化從「規劃估算」變「依實際帳單」。
- A6 有資料 → 可新增「功因罰款防線」與超約並列。
- B1–B5 校正 → 汰換投資回收成為「可貼進預算申請」的正式效益表。
- C1–C2 補齊 → 從「北電錶區」升級為「全校數位分身」。
- C3–C4 補齊 → 從「單時點/型態分析」升級為「可信時序與季節預測」。
